# 训练前固定的实验方案

2026-11-08。运行位置：Windows 主机的既有 Anaconda data310，PyTorch 2.6 CPU。没有在 VMware 训练，没有创建新 Python 环境。

目标：将小型中文预训练编码器微调为 query 与 passage 的二分类 Cross Encoder，用相关性分数进行排序。不是从零训练，不是对百炼云模型修改权重。

模型：uer/chinese_roberta_L-2_H-128，版本固定在 resources.json。新增二分类打分头，微调编码器与分类头。公开数据：C-MTEB/T2Reranking 的 dev 切分。因为发布文件只有 dev，本实验内部再划分训练、验证与测试，不能宣传为官方完整基准结果。

先按固定随机顺序选取互不重复且均包含正负例的 query 组，训练 1000 组，验证 200 组，测试 400 组。各组选择最多 2 个正例与 6 个负例，候选顺序固定打乱。精确规范化 query 与候选文本在各切分间均不得重复；不符合的组被排除，并保存排除计数。近重复和原始预训练污染无法完全排除，列作局限。

训练三次随机种子 42、43、44，固定学习率 2e-4、AdamW、weight_decay 0.01、batch_size 16、max_length 128、最多 3 个 epoch；梯度裁剪 1.0；交叉熵损失。每个 seed 只用验证集 MRR@10 选 epoch，不使用测试集选参数。种子在第一次训练前固定。选择的数值是资源约束下的试点配置，不作最优声明。

对照：同一编码器加随机初始化分类头的训练前模型，以及确定性字符二元 BM25。使用同一组候选与标签。指标为 MRR@10、nDCG@10、Hit@1、Hit@5；报告三次训练均值和样本标准差，保存逐 query 排名与指标。对 BM25 的主指标差异按 query 配对 bootstrap 2000 次给出 95% 区间。仅在模型选择完成后评估测试集，不按结果反复试参。

本实验是公开中文检索数据的小规模方法验证，论文内容不进入训练或公开数据下载请求。现有论文 14 题已被人工观察，不能充当全新盲测集。未实测论文问答改善或部署前，简历不得写论文问答准确率提升、线上部署或云端 qwen3-rerank 被替换。
